## How to Use

For new line, type <kbd>&#92;</kbd>+<kbd>⏎</kbd>

````md magic-move

```shell
````

Type <kbd>!</kbd> to enter shell mode.

````md magic-move
```shell
╭───────────────────────────────────────────────────────────────────────────────────╮
│ ! git --no-pager show                                                             │
╰───────────────────────────────────────────────────────────────────────────────────╯
```
````

If agent (or you) got stuck in pager <kbd>ctrl</kbd>+<kbd>f</kbd>,<kbd>q</kbd>
